# TOLA Network: External Digital Gifts Tokenization Architecture

## Scope & Purpose
Specifies the tokenization pipeline, verification protocol, and on-chain ownership representation for external digital gifts and social collectibles.

> [!IMPORTANT]
> **NO NATIVE GIFTS OR BADGES**
> TOLA Network does NOT create native messenger gifts, does NOT create Gifts Numbers, and does NOT maintain native profile badge registries. All digital gifts and collectibles originate on external platforms and are tokenized via independent third-party tokenization applications into TLS-721 tokens (`contracts/TolaExternalAssetToken.sol`).
