# SUBSYSTEM: Peer-to-Peer Networking & Gossip Protocol

## Objective
Design and implement the robust, decentralized peer-to-peer networking layer for TOLA Network, providing peer discovery, encrypted transport, Sybil resistance, and high-efficiency gossip propagation.

## Why It Exists
A blockchain cannot function without a resilient overlay network. An adversary capable of eclipsing nodes or choking gossip propagation can partition the network, delay finality, or censor transactions.

## Dependencies
- `prompts/03-cryptography.md`
- `prompts/08-serialization.md`

## Non-Goals
- Running centralized tracker servers or single-point relay proxies.

## Requirements
- Foundation: **libp2p** framework (utilizing `rust-libp2p`).
- Transport: TCP and QUIC with **Noise Protocol** (XX handshake) transport encryption.
- Peer Discovery: **Kademlia DHT** with bootstrap bootnodes and local peer table persistence.
- Message Propagation: **GossipSub v1.1** with active message scoring, duplicate suppression, and mesh maintenance.
- Dedicated Topics:
  - `/tola/tx/1.0.0`: Transaction gossip.
  - `/tola/block/1.0.0`: Proposed block broadcast.
  - `/tola/consensus/1.0.0`: BFT voting and commit signatures.

## Security Requirements
- Eclipse attack mitigation: Strict limit on connections per `/24` IPv4 subnet (or `/48` IPv6).
- Sybil penalty: Peers broadcasting invalid blocks or malformed transactions are severely penalized and banned.
- DoS protection: Aggressive per-peer bandwidth rate limiting.

## Failure Modes
- Network partition due to routing table poisoning.
- High gossip latency during cross-continental block broadcasts.

## Testing Requirements
- Local multi-node network simulation (10 to 50 nodes in Docker).
- Chaos tests simulating packet drops ($10\%$) and high latency ($200\text{ ms}$).

## Performance Requirements
- Block propagation to $90\%$ of nodes in $< 500\text{ ms}$ globally.

## Migration Requirements
- Multi-protocol negotiation via `multistream-select` for seamless protocol upgrades.

## Acceptance Criteria
- P2P specification documented in `docs/networking/p2p.md`.
- libp2p protocol IDs and topic topologies standardized.
